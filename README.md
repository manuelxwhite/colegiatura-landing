# Colegiatura Landing Page

Landing page for [colegiatura.mx](https://colegiatura.mx) — Cobranza Escolar Inteligente.

Built with Tailwind CSS (CDN). Hosted on GitHub Pages.

## Waitlist Form

The form uses [Formspree](https://formspree.io). To activate:

1. Create a free Formspree account
2. Create a new form
3. Replace `CHANGE_ME` in the form `action` URL in `index.html` with your Formspree form ID
4. Commit and push

## Custom Domain

Domain `colegiatura.mx` is configured via the `CNAME` file. DNS must point to GitHub Pages:

- `CNAME  colegiatura.mx  manuelxwhite.github.io`
